# OpenSpec — historical archive

This folder is a **frozen historical record**. It is no longer the active planning workflow for Mundo 3D.

- **Scope:** capability specifications (`specs/`) and closed change cycles (`changes/archive/`) written with OpenSpec through September 2026.
- **Superseded by:** Organic Driven Development task documents in [`odd/tasks/`](../odd/tasks/), which record current requirements, decisions, and verification evidence per feature.
- **Known drift:** several specs describe the earlier PICO-8 pixel-art identity, the EJS views, the carousel, the CRT toggle, and the floating WhatsApp button. Those were removed from the product. The current visual system is documented in [`DESIGN.md`](../DESIGN.md) and [`design/taller-maker-styleguide.html`](../design/taller-maker-styleguide.html).

Treat any statement here as historical context, not as proof of current behavior. The code, its tests, and `PRODUCT.md` are the source of truth.
